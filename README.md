A 5-7-5 haiku about debugging, written for the [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty on make.fun:

> cursor blinks at three
> the log file says nothing new
> yet the bug blinks back

The program writes exactly those three lines to `/output/entry.txt`, with no trailing newline.

## Run

```sh
node main.ts
```
